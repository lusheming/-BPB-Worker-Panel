## 💡 为什么客户端选了“日本/印度”，ip.me 查出来的 IP 还是美国？

### 1. 入口（Inbound 优选 IP）vs 落地出口（Outbound 真实 IP）
- **优选 IP (Clean IP)** 是 **入口**：
  你在面板填入的优选 IP（如 `104.16.x.x` 或 `jp.090227.xyz`）是 Cloudflare Anycast CDN 的前端边缘服务器。
  它的作用是让你的电脑到 Cloudflare 的网络连通更顺畅、延迟更低（比如从日本或香港机房进网，延迟只有 300ms 且不丢包）。
- **Cloudflare Worker** 是 **落地出口**：
  Cloudflare Worker 是云端无服务器程序。当它代表你去访问目标网站（如 `ip.me`、Google 等）时，发起的网络请求统一走的是 Cloudflare 官方出网网关（Cloudflare WARP 网络），**默认全部分配为美国洛杉矶的 IP（IPv6: `2a09:bac1:...`，ISP: Cloudflare Warp）**。
- **结论**：所有基于纯 Cloudflare Worker 的代理节点，无论入口测速优选了哪个国家，**访问网站时的实际落地 IP 默认都是美国**！

## 🎯 如何使用【自定义节点】实现真实落地 IP？

如果你手头有其他特定国家节点（如印度、日本 VPS 或机场提取的节点）：

1. **直接粘贴节点配置**：
   进入 BPB 控制面板，切换到 **【⭐ 自定义节点】** 标签页，直接粘贴 Clash YAML 格式：
   ```yaml
   proxies:
   - name: "My_Trojan_Node"
     type: trojan
     server: 52.220.179.60
     port: 443
     password: "RZ17t2RoFwYLB6w8"
     sni: "52.220.179.60"
     skip-cert-verify: true
   ```
2. **智能转换格式**：
   点击输入框下方的 **【🔄 智能解析并转换 (YAML ➔ 链接)】**，系统会自动将其转换为标准通用链接：
   `trojan://RZ17t2RoFwYLB6w8@52.220.179.60:443?security=tls&sni=52.220.179.60&allowInsecure=1#My_Trojan_Node`。
3. **并入订阅 / 设为链式代理**：
   - 点击 **【✈️ 设为当前链式代理】**：自动填入前置链式代理，生成带有 `🔗 [真实落地]` 的双重加速节点；
   - 点击底部的 **【保存并应用设置】**：该节点也会作为独立节点直接加入到 Clash Verge 等客户端的订阅列表中！

## 使用方法：Cloudflare Pages 搭建
1. Fork 本存储库到自己的 GitHub。
2. 登录 Cloudflare 控制台 → 点击 **Workers & Pages** → **创建应用程序** → 选择 **Pages** → **连接到 Git**；
3. 选择刚刚 Fork 的本存储库，构建设置保持默认（无需填写构建命令与输出目录），点击保存并部署；
4. 部署成功后，在 Pages 项目的 **设置 (Settings)** → **环境变量 (Environment variables)** 中添加如下必要变量：

| 变量名 | 说明 |
| :---: | :--- |
| **UUID** | 必要；[在线生成 UUID](https://1024tools.com/uuid) ，用于生成 VLESS 节点身份凭据 |
| **TR_PASS** | 必要；自定义密码，用于生成 Trojan 节点密码 |
| **kv** | 必要；绑定一个 KV 命名空间（绑定变量名填写小写的 `kv`） |

5. 绑定完环境变量与 KV 后，在 **部署 (Deployments)** 页面点击最新的部署记录右侧 **...** → **重试部署 (Retry deployment)**。
6. 访问面板：部署完成后，在你的 Pages 域名或绑定域名后加上 `/panel` 进行访问（例如 `https://你的域名/panel`）。首次访问时设置的管理密码将安全保存在绑定的 KV 中。
